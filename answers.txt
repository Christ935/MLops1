Q1
uv init created the basic Python project structure. .python-version stores the Python version used by the project. pyproject.toml contains the project configuration, metadata and dependencies. README.md contains documentation for the project. The src/lab1 directory contains the Python package source code and __init__.py identifies it as a Python package.

Q2
dvc init created the .dvc directory and .dvcignore. .dvc/config contains the DVC project configuration. .dvc/.gitignore prevents internal DVC temporary/cache files from being tracked by Git. .dvc/tmp contains temporary internal DVC files. .dvcignore tells DVC which files it should ignore. The non-secret DVC configuration files and .dvcignore should be committed to Git, while temporary files should not be committed.

Q3
dvc remote modify origin --global user Christ935
dvc remote modify origin --global password token
 Because --global was used, the DagsHub credentials are stored in the user's global DVC configuration outside the Git repository. DVC also supports repository configuration, --local configuration and --system configuration. Credentials and access tokens should never be pushed to GitHub because they are secret.

Q4
After running "dvc add data", DVC added the data folder to .gitignore.
This prevents Git from tracking the actual dataset because the dataset is
managed and versioned by DVC instead.

Q5
The data.dvc file is a DVC pointer file. It contains metadata about the
dataset such as its hash/checksum, size, number of files and path.
Git tracks this small pointer file instead of tracking the actual dataset.
